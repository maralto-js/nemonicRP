# 🤝 Como Contribuir

Obrigado por querer ajudar NemonicRP!

## 📋 Antes de Começar

1. **Cheque issues existentes** - talvez alguém já esteja fazendo
2. **Abra uma issue primeiro** - discuta sua ideia antes de codar

## 📝 Boas Práticas

- **Títulos claros** - "Adiciona sistema de jobs" não "fix stuff"
- **Descreva mudanças** - explique PORQUE mudou
- **Testes** - certifique-se que funciona
- **1 feature por PR** - não misture coisas

## 🏷️ Labels

- `bug` - correção de bug
- `enhancement` - nova feature
- `documentation` - docs
- `P1-urgent` - prioridade alta
- `P3-low` - pode esperar
